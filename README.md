# Stock Volatility Tracker (주식 변동성 추적기)

주식의 일일 변동률을 추적하고 통계적 시그마(표준편차) 값을 계산하는 도구입니다.

## 기능

- 주식 티커를 입력받아 최근 1년간의 일일 데이터 수집
- 전일 대비 변동률(%) 계산
- 변동률의 평균과 표준편차 계산
- 1σ, 2σ, 3σ 구간 계산 및 출력
- 내일 몇 %가 변하면 각 시그마를 넘는지 예측

## 설치 방법

```bash
pip install -r requirements.txt
```

## 사용 방법

### 실제 주식 데이터로 실행

```bash
python sigma_calculator.py
```

실행 후 주식 티커를 입력하세요:
- 미국 주식: `AAPL`, `TSLA`, `GOOGL` 등
- 한국 주식: `005930.KS` (삼성전자), `000660.KS` (SK하이닉스) 등

### 샘플 데이터로 테스트

네트워크 문제나 API 접근 제한이 있는 경우, 샘플 데이터로 프로그램을 테스트할 수 있습니다:

```bash
python test_sample.py
```

## 시그마(σ) 해석

- **1σ**: 정규분포에서 약 68.3%의 데이터가 이 범위 안에 존재
  - 내일 변동률이 이 범위를 벗어날 확률: 약 31.7%

- **2σ**: 정규분포에서 약 95.4%의 데이터가 이 범위 안에 존재
  - 내일 변동률이 이 범위를 벗어날 확률: 약 4.6%

- **3σ**: 정규분포에서 약 99.7%의 데이터가 이 범위 안에 존재
  - 내일 변동률이 이 범위를 벗어날 확률: 약 0.3% (매우 드묾)

## 프로그래밍 방식 사용

```python
from sigma_calculator import StockVolatilityTracker

# 추적기 생성
tracker = StockVolatilityTracker('AAPL', period_days=365)

# 전체 분석 실행
tracker.analyze()

# 또는 단계별 실행
tracker.fetch_data()
tracker.calculate_daily_returns()
tracker.calculate_sigma()

# 시그마 레벨 가져오기
sigma_levels = tracker.get_sigma_levels()
print(sigma_levels)
```

## 주의사항

- 과거 데이터를 기반으로 한 통계이므로 미래를 보장하지 않습니다
- 블랙스완 이벤트(예상치 못한 큰 변동)는 예측할 수 없습니다
- 투자 결정은 본인의 판단과 책임 하에 하시기 바랍니다
